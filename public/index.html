+ CONECTANDO O MOTOR

O Potato usa sua propria instancia Cobalt. No servidor, configure COBALT_API_URL e, se necessario, COBALT_API_KEY.

Para iniciar tudo localmente:

docker compose up -d --build

A interface abre em localhost:3000 e a API em localhost:9000. A chave nunca e enviada ao navegador.

[03] / README.TXT

Feito de caracteres.
Movido a batata.

Um downloader pessoal inspirado na simplicidade do Cobalt, com uma identidade 100% ASCII.

[01] / DIRETO AO PONTO

Cole um link publico, escolha video ou audio e gere o arquivo. Posts com varias midias aparecem como uma lista para voce escolher.

[02] / PRIVACIDADE

Sem analytics, fontes externas ou historico persistente. O link e enviado ao servidor Potato e a instancia Cobalt configurada para processar a midia.

[03] / SEU MOTOR

Interface independente, backend Cobalt auto-hospedado. O Potato nao depende da API publica do cobalt.tools.

[04] / BOM SENSO

Baixe conteudo que voce criou ou tem permissao para salvar. Conteudo privado, DRM e restricoes das plataformas podem impedir o download.
